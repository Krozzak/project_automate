🚀 Résumé des meilleures features leaked de Claude Code (Anthropic)

Un gros leak hier a révélé l'architecture interne de Claude Code (l'outil CLI/agent de coding). Voici les features les plus intéressantes à reproduire dans nos workflows :

Top features :

- KAIROS : Agent daemon qui tourne en arrière-plan 24/7. Il observe le projet, agit proactivement et fait un « auto-dream » la nuit pour consolider la mémoire.

- Multi-Agent Orchestration : Un coordinateur pilote plusieurs sub-agents (Plan, Explore, Task). Idéal pour les refactors complexes et tâches longues.

- BUDDY : Petit compagnon virtuel gamifié qui réagit à ton coding (stats humouristiques). Rend les longues sessions plus agréables.

- Undercover Mode : Claude fait des commits/PR comme un vrai dev humain (sans jamais mentionner l'IA).

- Persistent Memory + ULTRAPLAN : Mémoire longue durée via fichiers + planification déléguée profonde.

Comment on peut l'utiliser rapidement :

On peut déjà reproduire la plupart avec l'API Claude + quelques prompts modulaires + outils simples (LangGraph, scripts Python ou Cursor).

Le plus puissant :
KAIROS-style (agent persistant) + multi-agents pour automatiser les tâches répétitives et les gros refactors.

Je peux préparer un template de prompts + un mini-script de départ si ça vous intéresse. Qu'en pensez-vous ?
